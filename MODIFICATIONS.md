# ThinkPilot modifications

ThinkPilot is a modified derivative of [HKUDS/DeepTutor v0.2.0](https://github.com/HKUDS/DeepTutor/tree/v0.2.0). This document provides a prominent record of modifications to the upstream work.

## 2026-08-21

- Renamed the product and user-facing identifiers from DeepTutor to ThinkPilot.
- Reorganized the public project metadata, documentation, ignore rules, Docker configuration, logging names, and browser storage keys.
- Added and refined subject-aware routing, Teacher workflows, Feynman assessment, guided learning, notebook, review, and knowledge-management behavior.
- Updated the FastAPI and Next.js application surfaces, localization checks, frontend navigation, tests, and continuous integration.
- Removed local credentials, generated data, build artifacts, caches, stale backups, and unrelated repository assets.
- Added AGPL-3.0-only licensing metadata, upstream attribution, and a visible source-code link for network users.

Copyright in the unchanged or adapted upstream portions remains with the original DeepTutor authors and contributors. Copyright in the ThinkPilot-specific modifications is held by their respective contributors.
